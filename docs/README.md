# 书稿配套文档索引

本目录保存《Code Visualization》的定位、大纲、质量标准、写作流程和案例约定。正文按正常技术书籍组织；本目录用于支撑写作与验收，不进入读者主阅读路径。

目录骨架已冻结（见 `book-outline.md`）；RC 重点是章内丰富度、权威引用与成书资产，不靠继续加章。

当前内容主线：

> 先讲代码可视化与程序分析原理，再选择少量核心工程场景承接，最后推进到 AI 时代的应用，并用实践项目跑通闭环。

## 使用顺序

1. 先看 `book-outline.md` 确认目录。
2. 再看 `definition-of-done.md` 确认完成标准。
3. 用 `content-positioning.md` 确认读者、边界和写作深度。
4. 用 `chapter-quality-matrix.md` 管理章节状态、样章优先级和需补充信息。
5. 用 `sample-case/README.md` 与 `examples/mini-shop/`（含 `artifacts/`）复用贯穿模拟案例。
6. 需要补充背景和来源时看 `research-ai-code-visualization-2026.md`。
7. 开始逐章写作时按 `ai-writing-framework.md` 的资料卡和章节 brief 流程执行。
8. 需要阶段性推进顺序时看 `content-confirmation-and-optimization-plan.md`。
